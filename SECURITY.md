# Security policy

## Supported versions

Before the first npm release, security fixes land on `main`. After release, only the latest published version is supported.

## Reporting a vulnerability

Do not open a public issue. Use [GitHub private vulnerability reporting](https://github.com/jkomyno/runesm/security/advisories/new). If that form is unavailable, email the maintainer address listed in `packages/runesm/package.json`.

Include affected versions, reproduction steps, impact, and any suggested mitigation. Avoid including secrets or unrelated personal data.
